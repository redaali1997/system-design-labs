# System Design Labs

Hands-on labs for practicing System Design concepts against a real running system instead of just reading about them — each unit gets a small, self-contained project you can spin up, break, measure, and fix.

## Labs

- **[caching-lab](caching-lab/)** — NestJS + MySQL + Redis playground for cache-aside, TTL/staleness trade-offs, invalidation, and cache stampede protection, measured with k6 load tests against a 50,000-row dataset.

More units will get their own folder here as they're worked through.
